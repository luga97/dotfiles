Máscara RGBA (R espesor / G humedad / B viscosidad / A lodo) con fuente de verdad en PackedByteArray CPU, expuesta vía SubViewport + Sprite2D blend_disabled (para no corromper canal A) → ViewportTexture → DynamicDirtShader.gdshader (parallax por gradiente, NORMAL_MAP procedural, wetness rough 0.05). Tests headless: `godot --headless -s res://tests/test_surface.gd` (5/5 OK). Quirks aprendidos: PlaneMesh vive en plano XZ (normal +Y); GPUParticles3D usa `explosiveness` (no `explosiveness_ratio`, que es de CPUParticles); Mesh.ARRAY_TEX_UV (no ARRAY_TEXUV); Rect2i.merge para unir rects. #project #godot
