### Lessons Learned
- `main-branch-guard.ts` no es un hook de git: es una extensión pi que inspecciona el string del comando bash; por eso `--no-verify` no lo saltea.
- El guard bloquea cualquier comando compuesto que contenga `git commit|push|merge` mientras se está en `main` (incluso `git switch ... && git commit`); separar el cambio de rama y el commit en llamadas distintas.
- GitLab en namespace personal auto-crea proyectos privados on-push; la primera rama pusheada queda como `default_branch` (corregir con `PUT projects/:id -f default_branch=main`).
- Esta versión de `glab` no soporta el flag `--jq` en `glab api`; usar salida cruda con `grep`.
