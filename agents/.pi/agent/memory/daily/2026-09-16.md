## Extensión /usage de pi: soporte Z.ai

- `~/.pi/agent/extensions/usage.ts` (extensión propia de Luis) ahora soporta el proveedor `zai` además de `openrouter`.
- Endpoint verificado con la clave del Coding Plan: `GET https://api.z.ai/api/monitor/usage/quota/limit` (Bearer, sin spec pública).
- Respuesta: `{code, success, data: {level, limits: [{type, unit, number, percentage, nextResetTime(ms), remaining, usageDetails[]}]}}`.
- Tipos vistos en plan lite: `CREDIT_LIMIT`; `unit` 3=ventana de N horas, 6=semanal (4=días, 5=mensual según oh-my-pi).
- Clave resuelta vía `getProviderAuth("zai")` → `ZAI_API_KEY` → `auth.json`. Plan actual: **lite**.
