## Mensajes de commit del sync automático de dotfiles generados con pi

- `~/dotfiles/scripts/dotfiles-sync.sh`: el commit automático ya no usa `sync(auto): host fecha`. Nueva función `gen_commit_msg()`: pasa stat + diff (truncado a 8KB) a `pi -p --no-session --no-tools` (zai/glm-5.3-flash) y usa la primera línea como asunto; metadata (host+fecha) quedó en el cuerpo del commit.
- Fallback: si pi falla, agota timeout 90s o el diff matchea `SECRET_RE` (no se manda a la API), cae al mensaje genérico — el sync nunca se rompe.
- Bugs descubiertos: bajo systemd user `pi` no está en PATH (solo shim de mise en shells) → `resolve_pi()` con fallback a `~/.local/share/mise/installs/pi/latest/pi/pi`; y el binario `hostname` NO existe en Arch → usar `uname -n` (los commits viejos tenían host vacío).
- Costo: 1 llamada flash por sync con cambios (~13s), timer cada 15min. Home-server corre el mismo script vía repo; si allí resolve_pi falla, degrada a mensaje genérico. #infra #dotfiles
